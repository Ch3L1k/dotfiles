# Publication scope

This is a curated, sanitized configuration snapshot, not a backup of the whole home directory.

- Excluded: account data
- Excluded: browser profiles
- Excluded: fish_variables and shell history
- Excluded: Steam userdata
- Excluded: Telegram tdata
- Excluded: Discord/Vencord settings with account state
- Excluded: Codex chats and credentials
- Excluded: geolocation/weather location
- Excluded: wallpaper history, favorites and private avatar
- Excluded: mount definitions, fstab, bootloader and system services
- Excluded: disabled legacy dock watcher and old personal wallpaper integration

- Home paths use @HOME@ placeholders
- CachyOS Fish vendor config is optional
- Legacy xhost root grant excluded; source installation remains unchanged
